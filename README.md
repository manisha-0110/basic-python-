String Processing and Validation

Definition: Techniques to manipulate and analyze strings, including filtering characters, normalization (e.g., lowercasing), and pattern checks like palindromes using slicing or iteration.

Palindrome Checking

Definition: Determining whether a string reads the same forward and backward after removing non-alphanumeric characters and normalizing case.

Numeric Computation and Mathematical Validation

Definition: Operations on numbers to evaluate properties such as perfect squares using arithmetic or integer-based checks.

Perfect Square Verification

Definition: Checking whether a number is a perfect square by comparing the integer square root squared with the original number.

Randomization and Simulation

Definition: Using pseudo-random functions to simulate real-world scenarios such as scheduling or shuffling sequences.

Combinatorics (Pair Generation)

Definition: Generating all possible unique pairs or combinations from a set, often using nested loops.

List Operations

Definition: Creating, modifying, and iterating over lists, including appending elements, slicing, and transformations.

String-to-List Conversion

Definition: Converting strings into lists of characters to allow element-wise manipulation.

Greedy Elimination Algorithm

Definition: Iteratively removing elements from a list based on a computed index (e.g., FLAMES logic using modular arithmetic).

Modular Arithmetic

Definition: Performing arithmetic operations with wrap-around using modulus, commonly used in cyclic indexing.

Prefix Sum (Running Sum)

Definition: Transforming a list so each element represents the cumulative sum up to that index.

Matrix Representation

Definition: Using nested lists to represent 2D grids for structured data or pattern generation.

Pattern Printing

Definition: Generating visual patterns using loops and conditional logic over matrix indices.

Menu-Driven Programming

Definition: Designing programs that repeatedly prompt users with options and execute corresponding functions based on input.

Function Definition and Invocation

Definition: Encapsulating reusable logic in functions and calling them with parameters or user input.

Control Flow Statements

Definition: Using if, elif, else, loops, and break to control program execution paths.

Input/Output Handling

Definition: Reading user input via input() and displaying results using print().

Prime Number Checking

Definition: Determining whether a number is prime by testing divisibility up to its square root.

Digit-Based Computation

Definition: Processing individual digits of a number using string conversion or arithmetic.

Sum of Digits

Definition: Calculating the total of all digits in a number.

Higher-Order Functions (all)

Definition: Applying a condition across iterable elements, returning True only if all elements satisfy the condition.

Recursion

Definition: A function calling itself to solve a problem by breaking it into smaller subproblems.

Recursive Tree Expansion

Definition: A recursion pattern where multiple recursive calls are made, leading to exponential growth in execution paths.

Base Case in Recursion

Definition: The terminating condition that stops further recursive calls.

Prime Factorization (Recursive)

Definition: Breaking a number into its prime factors using recursion and smallest divisor logic.
